# 量化趋势指标二次披露与深度参考手册

本手册作为 `trend_analysis` 技能的二次深度披露文档，提供底层指标计算公式、多空博弈解释与置信度评价准则。

---

## 一、 核心指标计算模型

### 1. 5日均线 (MA5 - Moving Average 5 Days)
$$MA5 = \frac{1}{5} \sum_{i=1}^{5} Close_i$$
- **技术含义**：反映最近一周（5个交易日）参与者的平均持仓成本线。
- **均线偏离度 (Bias Ratio)**：
  $$Bias5 = \frac{Close_{latest} - MA5}{MA5} \times 100\%$$
  - $Bias5 > +3\%$：短线存在超买乖离，谨防冲高回落；
  - $Bias5 < -3\%$：短线存在超跌反弹动能。

### 2. 区间价格波动幅度 (Range Amplitude)
$$Amplitude = \frac{High_{max} - Low_{min}}{Low_{min}} \times 100\%$$
- 振幅 $< 4\%$：窄幅缩量整理，变盘在即；
- 振幅 $> 8\%$：多空剧烈博弈，短线波动剧烈。

## 二、 量价配合形态矩阵

| 价格形态 | 成交量特征 | 技术含义与后市概率 |
| :--- | :--- | :--- |
| **放量上涨** | 成交量放大 $\ge 30\%$ | 主力增量资金进场，趋势向上可靠度极高 |
| **缩量阴跌** | 成交量逐日递减 | 市场承接盘匮乏，属于典型阴跌走弱，谨慎抄底 |
| **放量滞涨** | 创区间天量但收阴/十字星 | 高位筹码松动，主力出货嫌疑，短线见顶信号 |
| **缩量回踩 MA5** | 回踩均线不跌破且缩量 | 蓄势整固洗盘，洗盘后大概率继续上攻 |

---

## 三、 报告归因打分与置信度规范

在输出走势归因时，请结合以下 3 项打分：
1. **方向一致性**：净涨跌幅方向与最新价相比 MA5 的位置是否同向？（同向：高置信度；反向：震荡或背离）；
2. **极端价格结构**：是否存在连续的 Higher Highs（高点抬升）或 Lower Lows（低点下移）；
3. **样本时效限制说明**：必须明确告知用户样本周期仅为 5 日，分析仅作为超短线参考。
