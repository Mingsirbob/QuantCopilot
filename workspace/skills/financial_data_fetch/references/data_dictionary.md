# 金融行情数据字典与字段清洗对照表

本文件作为 `financial_data_fetch` 技能的二次深度披露文档，提供同花顺等 MCP 行情接口的核心字段语义与单位换算规范。

---

## 一、 核心行情字段对照表

| 字段名 | 中文含义 | 单位/类型 | 处理与清洗规范 |
| :--- | :--- | :--- | :--- |
| `open` | 开盘价 | 元 (float) | 保留 2 位小数 |
| `high` | 最高价 | 元 (float) | 期间最高极值 |
| `low` | 最低价 | 元 (float) | 期间最低极值 |
| `close` | 收盘价 / 最新价 | 元 (float) | 核心计算基准 |
| `volume` | 成交量 | 股 (int) | 注意转换为标准“股”或“手”（1手 = 100股） |
| `amount` | 成交金额 | 元 (float) | 超过 1 亿元时格式化为“xx.xx 亿元”呈现 |
| `change_pct` | 单日涨跌幅 | 百分比 (float) | 例如 2.35 表示 +2.35% |
| `trade_date` | 交易日期 | YYYY-MM-DD | 标准 ISO 字符串 |

---

## 二、 边界异常清洗规程

1. **停牌或休市日处理**：
   - 若接口返回 `null` 或单日成交量为 0，需注明停牌或休市，不可计入均线计算的分母中。
2. **复权标准**：
   - 日K线默认使用**不复权**或**前复权**，如遇除权除息日价格跳空，需在研报中特别备注“该区间包含分红派息/除权”。
